# 报文调试版（2026-10-16）

当前窗口标题为“配置驱动协议转换”。本文件描述现行操作，取代其他历史设计中的发送门禁要求。

## 点击发送

- 发送、手动查询始终可点击。未启用、未校验、未确认、未保存、正在等待回告、设备忙/未知均不禁用按钮。
- 读取当前表单；存在未应用高级JSON时优先使用该JSON。发送时生成临时配置，既不落盘，也不改变草稿保存/校验/启用状态。
- 表单改命令码或设备地址后可直接发，不要求重复保存。每个入队请求保存自己的参数及源/目标地址，后续编辑不会改变正在等待的回告匹配或已入队请求。
- 调试快照移除字段最小/最大范围，将软件行程扩展到协议24位可表示范围。速度、编号、载荷布局等必须能编码成真实协议字节，无法解析或编码时就地显示原因，不复用上一条帧。
- 旧相对运动也直接编码模式2及指定距离，不主动先查位置。前进/后退绝对模式4、停止/复位的固定模式/动作/零距离保持原字节定义。
- 8位序号循环使用，不再发256条就要求重连。当前请求仍检查地址、命令及序号；序号回绕后，极迟的同地址同命令旧回告可能与新请求重号，这是调试序号的边界。
- 连续点击发送进入串行队列，完整写帧和应答等待仍按序处理；设备拒绝、超时和断连会明确显示，本地不自动重发。机械动作是否完成不作为按钮条件。

串口未连接时点击发送会显示“下游串口未连接”；无效JSON、客户报文不匹配或尚无编码实现时显示报文生成错误。不能生成字节的情况不通过禁用按钮隐藏。

## 保存与预览

底部直接显示三个同尺寸按钮：“保存配置、导入配置、导出配置”，不再使用下拉菜单。手动校验、启用操作已移除，保存、导入及启动恢复时自动检查并启用有效内容；无效配置仍保存但不启用，就地显示具体原因，修复后重新保存。自动启用不连接串口、不发送报文，不重置序号或打断原请求。

保存保留各页表单及已添加的映射，高级配置页隐藏，复杂JSON关系可通过文件导入导出处理。顶部配置版本栏、参数确认框及独立省略字段勾选区移除；停止、复位和查询默认不使用客户参数。普通顺序格式仍解析完整字段，只有mappedCommand旧模式保留无参数短报文的实际省略。错误原因显示在底部，导出仍针对已保存配置；调试发送继续直接使用当前编辑内容。

退出未保存提示和写盘失败保护不变。“预览”仍使用已保存配置，发送重新解析当前输入和编辑内容，发送结果标题明确说明来源。

## 验证

MSVC2022 14.44 / Qt5.14.2 MSVC 32位构建。回归覆盖无保存/校验/启用/确认时直接点击、当前未保存命令及超出软件范围的数值、未应用JSON、错误显示、不改草稿文件、600次编码连续序号、相对动作无前置查询和排队地址快照。使用模拟传输，不直接操控实机。

下一步具体整理：让“预览”也使用当前编辑快照，与直接发送共用输入来源，减少已保存草稿与当前编辑结果混淆；保留明确保存按钮。

本轮界面简化验证：应用构建成功，52项界面回归、Windows原生11项针对性验证通过，0失败/跳过（含初始化/清理），无编译警告。覆盖无参数运动/查询/SDK、固定目标与字段改名、已有省略配置及保存/导入/重启自动启用；未操作实机。

## 命令映射只增删

当前界面屏蔽选中行编辑。下方“添加新映射”独立于表格，点击行不会载入或写回。填写后点添加才追加一行；删除选中映射只删除该行。保存、发送都不提交尚未添加的新表单，重复客户命令不覆盖旧项。修改已有指令采用先删除再添加的操作。

添加、删除在表格下方；保存使用窗口底部统一入口。停止、复位和查询默认不使用客户参数，但普通顺序格式中的字段及分隔符仍须存在并通过校验；“解析格式”与映射是否使用字段无关。仅mappedCommand旧短报文可真正省略参数字段，例如Z映射复位可输入`/1ZR\r`。旧mappedCommand停止/复位映射缺少省略设置时，重新打开会在内存补齐，点击保存才写入原草稿；显式配置的列表不改变。详见[格式与未使用参数](format-driven-parsing.md)。
