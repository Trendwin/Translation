# XYZ 计算公式

在命令映射中选择“虚拟模块控制（XYZ）”，先设置客户列表输入项数，例如3项，再为X、Y、Z各自选择“fx 公式”。公式可混合客户参数、已保存的位置与校准参数以及数字常量。

公式窗口列出变量及其取值来源。前三个客户参数默认对应`a`、`b`、`c`；校准组的各项显示为`p1_1`、`p1_2`等，旁边明确标注组名和项号，可插入公式。例如：

| 目标 | 公式 | 含义 |
| --- | --- | --- |
| X位置 | `p1_1 + (a - 1) * 90` | 首孔X加上客户第1项决定的偏移 |
| Y位置 | `p1_2 + (b - 1) * 90` | 首孔Y加上客户第2项决定的偏移 |
| Z位置 | `p1_3 + c` | 校准Z加上客户第3项 |

这里90只是演示间距，软件不规定客户参数的业务含义，也不自动换算单位。实际公式和校准值由使用者按设备填写。每个轴的公式独立；虚拟模块编号仍单独设置。

支持加减乘除、括号、一元正负和十进制常量。只进行数值运算，不执行脚本。公式变量保存具体字段/预设标识和项号，修改预设显示名或调整组顺序不会改用其他组；删除来源或缩短列表后须修正失效引用。新增组不会自动改变已有公式绑定。

默认将最终结果四舍五入成整数，恰好一半时向远离0的方向取整，例如2.5→3、-2.5→-3；中间计算不逐步取整。也可明确选择要求整数、向下取整或向上取整。选择要求整数时，有小数即报错。

公式确认后仍是本条指令草稿，需要“添加到清单”或“保存本条修改”，最后“添加命令映射”并保存配置。取消公式窗口不提交修改；保存公式或校准参数均不会直接发送指令。

收到匹配的客户报文后，程序读取客户参数和校准值，计算各轴位置，再按现有流程生成趋盛报文。转换预览显示公式、变量取值与结果。除零、溢出、引用失效及目标值超出协议范围都会使整组转换失败，不产生部分指令。

可导入[公式示例](../examples/xyz-formulas.json)，在报文调试页输入`!MOVE=2,3,4\r`预览。示例组为`80,1075,30`，结果应为X=170、Y=1255、Z=34；不是实际设备校准数据。

## 配置表示

```json
{
  "kind": "formula",
  "formula": "p1_1 + (a - 1) * 90",
  "variables": {
    "a": {"kind": "field", "field": "values", "itemIndex": 1},
    "p1_1": {"kind": "field", "scope": "preset", "field": "plate-a", "itemIndex": 1}
  },
  "round": "nearest"
}
```

变量名使用英文字母、数字和下划线，首位不能是数字；绑定仅支持直接客户字段或预设引用，不嵌套公式。最多64个变量，公式最多1024字符、256个运算/数值节点，嵌套最多32层。中间运算使用有溢出保护的精确有理数，不能表示的中间结果会报错。旧的固定值、直接引用及linear表达式继续保留。
