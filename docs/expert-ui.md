# 简洁界面设计

本轮基于main 32ffdbd，面向熟悉趋盛协议的使用者。目标是让配置、映射、预览、发送和回告直接可见，减少常驻说明和暂时不需要的操作入口。

## 保留的核心操作

- 客户协议格式：ASCII/HEX、帧头帧尾、顺序字段及增删调整。
- 命令映射：完整59选项、CMD/名称搜索、来源字段或固定值、倍数、响应方式、保存草稿。
- 报文调试：预览、下游发送、原始回告、解析结果、状态、取消等待及状态查询。
- 设备连接：地址、电机编号、默认速度、行程、串口及参数确认。
- 配置：导入导出、校验启用、草稿/启用版本、高级JSON。

映射的独立帧尾和省略字段仍保留，它们决定报文的实际边界与布局。例如同一客户格式的运动有数值参数、查询无参数，不能因为简化界面就自动丢掉这些配置。帧尾输入留空表示使用共用帧尾。

## 删除的界面功能

顶部流程横幅、阶段提示、常驻协议说明、协议详情展开、完整目录浏览窗口、类别筛选、偏移与取整编辑、离线回告解析，以及公共底部日志面板。正常可发送选项不再重复标记；仅保留“待实现”“仅接收”“旧版”等影响选择的状态。

运行日志改为调试结果中的一个页签。发送条件未满足时显示短原因，错误发生时仍显示具体原因；草稿与启用状态分开显示。发送门禁、参数确认、超时及完成处理不变。

## 配置兼容与边界

删除偏移/取整控件不等于修改既有表达式。普通表单编辑来源、倍数、客户命令或响应方式时，保留原关系的offset、round、精确分数和扩展元数据。高级JSON仍能显示这些关系；本轮不再提供专用复杂计算表单。

移除目录浏览不缩减完整指令池，也不开放未实现发送能力。0x11四动作、旧配置兼容、默认速度及单下游串口模型均不改变。DT仍只是配置示例，解析器不添加客户协议专用分支。
