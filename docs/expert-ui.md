# 简洁界面设计

面向熟悉趋盛协议的使用者，主窗口保留五页：客户协议格式、命令映射、报文调试、设备与连接、高级配置。正常页面只显示编辑、发送及结果所需控件；日志放在调试结果页签，协议细节放入文档。

## 统一配置入口（2026-10-15）

界面统一使用“配置”，不再区分“保存到草稿”“导出草稿”等按钮名称。格式、映射、设备页的三个保存按钮合并为窗口底部“保存配置”，所有页面均可直接使用。旁边“配置”下拉菜单集中提供导入、导出、校验、启用，常驻配置入口由多个按钮减为两个。

保存提交各页表单和表格中已添加的映射，先结束当前单元格或数字控件编辑，再读取完整内容。尚未点击添加的新映射不参与保存。仅高级 JSON 修改时，同一按钮解析、保存 JSON 并刷新表单；两份内容同时修改时拒绝隐式选择，保留编辑与原文件。高级页保留“应用 JSON”，用于明确采用 JSON 内容。

配置继续使用原有原子写盘和本地路径`%LOCALAPPDATA%/Trendwin/Translation/draft.json`，已有文件无需迁移。配置可以先保存为不完整内容，校验错误单独提示。菜单的校验、启用、导出针对已保存配置；校验、启用与设备参数确认均不作为报文调试发送前提。

关闭时仅有未保存表单或未应用 JSON 才提示“保存 / 放弃 / 取消”。默认、Esc、关闭提示框均取消退出；保存复用统一入口，失败保留窗口。表单与 JSON 同时修改时禁用关闭提示的保存，要求先处理冲突；调试输入和搜索不触发配置修改提示。

## 命令映射只添加、删除

表格仅显示客户命令、执行动作、参数说明，选中行只确定删除目标。下方“添加新映射”独立于选中行；填写完成点击表格下方的“添加命令映射”后才追加末尾并清空表单。空白或无效内容不创建占位行，重复命令明确提示先删除旧项，不覆盖原记录。删除不改变尚未添加的表单。

已有相对配置直接显示“相对前进”“相对后退”，不加“旧版”前缀；配置与模式不变。新建池继续提供完整59选项、CMD/名称搜索及参数来源，不将旧兼容模板加入新建选项。

停止/复位默认省略命令后的客户参数字段；例如Z映射复位可使用`/1ZR\r`。加载旧配置时，仅对可变映射命令格式中缺少省略列表的停止/复位补齐`input.omitFields`。显式列表及其他元数据保持原值；明确保存前不改写文件。客户解析器继续按配置处理，不增加Z专用分支。

## 字段、参数与兼容

同一字段改名同步已有映射的来源及省略设置；增删、排序、类型变化刷新来源，失效关系明确指出，不自动选择替代字段。详见[field-adaptation.md](field-adaptation.md)。

普通映射保留来源字段、固定值、倍数；SDK参数使用“参数、来源、固定值”紧凑表格。停止/复位不显示距离控件。已有offset、round、精确分数及扩展元数据按原记录保留，高级JSON仍可查看；表单不提供复杂结构或任意字节发送入口。

所有命令使用格式页的帧尾，移除旧responsePolicy和映射独立帧尾设置。目录保留待实现、仅接收等影响使用的状态。教学横幅、协议详情、目录浏览窗口、分类、偏移/取整控件和离线回告解析不常驻界面。

## 调试与验证

发送、手动查询始终可点击。当前表单及已添加映射生成本次配置；有未应用JSON时调试发送使用JSON。不要求保存、校验、启用、确认或设备空闲；连续发送排队，不自动轮询或重发运动。应答与机械完成分开显示。详见[报文调试说明](packet-debug.md)。

本轮使用MSVC2022 14.44 / Qt5.14.2 MSVC 32位构建应用和界面测试。完整48项界面回归通过，覆盖统一跨页保存、JSON保存及冲突、菜单导入导出和校验启用，以及原有持久化、关闭、映射和报文生成流程。Windows原生48项通过并查看菜单与各页渲染；运行包隔离Qt安装目录后，5项统一保存及菜单验证通过（均含初始化/清理），编译无警告。验证只使用隔离配置和模拟传输，不操作实机。
