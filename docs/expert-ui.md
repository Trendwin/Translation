# 简洁界面设计

当前基于main 17b3d96，面向熟悉趋盛协议的使用者。目标是让配置、映射、预览、发送和回告直接可见，减少常驻说明和暂时不需要的操作入口。

## 保留的核心操作

- 客户协议格式：ASCII/HEX、帧头帧尾、顺序字段及增删调整。
- 命令映射：完整59选项、CMD/名称搜索、来源字段或固定值、倍数、保存草稿。
- 报文调试：预览、下游发送、原始回告、解析结果、状态、取消等待及状态查询。
- 设备连接：地址、电机编号、默认速度、行程、串口及参数确认。
- 配置：导入导出、校验启用、草稿/启用版本、高级JSON。

协议格式为映射的前提：同一字段行改名时，参数来源和省略设置自动同步全部映射；不让用户逐条修正同一个名称。增删、排序和类型变化刷新可选来源；失效关系明确指出，详见[field-adaptation.md](field-adaptation.md)。

映射表只保留“客户命令、执行动作、参数说明”三列，不再编辑反馈时机或独立帧尾。所有命令使用格式页的帧尾；无参数查询仍可显式省略字段。DT原始运动和查询若结束格式不同，分别使用相应格式配置，不在映射中覆盖帧尾。

## 删除的界面功能

顶部流程横幅、阶段提示、常驻协议说明、协议详情展开、完整目录浏览窗口、类别筛选、偏移与取整编辑、离线回告解析，反馈时机、独立帧尾，以及公共底部日志面板。正常可发送选项不再重复标记；仅保留“待实现”“仅接收”等影响选择的状态。映射摘要直接显示“相对前进”“相对后退”，不再加“旧版”前缀；原配置及运动模式不变。

运行日志改为调试结果中的一个页签。每个有效匹配回告立即更新解析结果，接纳与运动完成仍分开跟踪。界面载入及保存清除旧responsePolicy/input.footer，其他输入元数据和参数表达式保留。发送条件未满足时显示短原因，错误发生时仍显示具体原因；草稿与启用状态分开显示。发送门禁、参数确认、超时及完成处理不变。

## 配置兼容与边界

删除偏移/取整控件不等于修改既有表达式。普通表单编辑来源、倍数或客户命令时，保留原关系的offset、round、精确分数和扩展元数据。高级JSON仍能显示这些关系；本轮不再提供专用复杂计算表单。

移除目录浏览不缩减完整指令池，也不开放未实现发送能力。0x11四动作、旧配置兼容、默认速度及单下游串口模型均不改变。DT仍只是配置示例，解析器不添加客户协议专用分支。

## SDK普通参数

简单控制/查询使用同一紧凑参数表：参数、来源、固定值。来源首项显示有效默认值或必填提示，未映射时交由SDK补齐；不增加结构编辑器。只保留已有运动的单字段编辑方式，不能把风扇、阀、电压等参数误套成位置。主页面仍为五页；主动回告与原始帧立即显示。

## 关闭时保留编辑

有未保存表单或未应用高级JSON时才出现中文“保存 / 放弃 / 取消”对话框。默认按钮、Esc和提示框关闭均取消退出。先提交当前正在编辑的表格单元格及设备数字，再判断草稿状态。保存复用表单保存或JSON应用的落盘流程，失败保留窗口和编辑；放弃允许关闭，原落盘文件不变。表单和JSON同时修改时不自动选择一份，禁用保存并提示取消后处理。正常页面不增加说明或控件，调试输入与搜索不参与草稿修改判定。

2026-10-13，本轮基于已合并PR #19，新增8个关闭场景回归。下一轮计划保护导入配置时的未保存编辑，并集中复查关闭、保存、导入、JSON应用及状态提示，整理MSVC构建说明；按每2～3次修改集中复查的节奏执行。

## 手动查询状态（2026-10-15）

运动应答后不再自动查询，也不显示30秒动作完成超时。执行状态显示“已应答，动作完成未确认”，设备忙或未知不再禁用发送；没有在途请求时显示“就绪”，等待应答时显示“可发送（排队）”。沿用现有查询按钮，不增加常驻控件，也不要求查询后才能再次发送。此前自动完成跟踪说明以此为准。

2026-10-15后续调整：当前已改为直接报文调试，发送不再要求保存、校验、启用、参数确认或设备空闲，序号循环使用，相对动作不做自动查询。此前门禁说明以[报文调试版说明](packet-debug.md)为准。

## 添加映射不覆盖原行（2026-10-15）

此前“添加命令映射”会先保存当前编辑到旧选中行，再追加空白行。指令目标切换也有中间保存，所以填写Z/复位后点击添加会覆盖首行，并留下末尾空行。

添加现在先读取当前编辑值，未明确保存的修改作为新条目追加到末尾，保留旧行选中时的原始内容。插入、设置当前单元格与选中行期间阻断表格切换回调，再明确载入末尾编辑器；不依赖selectRow是否触发当前单元格事件。正在填写的空白新行再次点添加时只完成该行，不再创建另一空白行。明确保存草稿后更新原行基线，之后添加不会撤销已保存的修改。

## 仅添加、删除（2026-10-15）

按用户新要求屏蔽映射行编辑，取代前述PR #23的选中行编辑及追加保护设计。表格只显示映射摘要和选择删除目标；删除当前行不会改变正在填写的新表单。

下方标题改为“添加新映射”。填写完成点击添加后才创建一行，始终追加末尾并清空表单；空白或无效输入不创建占位行，重复客户命令明确提示先删除旧项。保存草稿和调试发送不隐式提交新增表单，不再维护旧选中行、编辑快照或中间写回逻辑。现有高级JSON映射的扩展元数据、精确参数关系及旧相对动作仍按原记录保存；字段改名继续同步已有映射和独立新表单的来源。

## 复位客户报文与按钮位置（2026-10-15）

添加按钮恢复到表格下方，与删除、保存并排；新增表单继续独立，选中已有行不会覆盖它。

原“无参数”摘要描述目标指令，但停止/复位没有像查询一样自动省略客户数据位，导致`/1ZR\r`先被客户格式长度校验拒绝。现在选择停止、复位默认勾选命令后的参数字段省略；切回有参数运动时取消默认省略。解析和编码仍按配置执行，不添加Z或某客户协议的专用分支。

加载旧草稿时，仅对可变映射命令格式中、缺少省略列表的停止/复位补齐`input.omitFields`；显式空列表、其他输入元数据和不支持省略的格式保持原值。原草稿文件在明确保存前不被改写。
