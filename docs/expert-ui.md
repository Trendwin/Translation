# 简洁界面设计

## 常用界面精简（2026-10-29）

四页与核心能力保持不变。顺序字段表默认隐藏最小值/最大值两列，勾选“数值范围”后编辑；收起不会清除数值，原有解析校验继续生效。固定字段需要时仍显示固定值列。

命令映射移除常驻教学段落、重复来源摘要和列表说明，相关规则保留在控件悬停提示与本文档。表单顶端对齐；空清单仅显示添加操作，选中步骤后显示新增下一条与删除，多条时出现排序按钮，有未保存修改才出现放弃按钮。清单仍只通过显式添加/保存改变；切换与最终提交不能暗中保存。

上下分区在尚未手动拖动时按表单内容分配空间：短表单把余量交给已有映射列表，阀、XYZ与多步骤表单获得更多编辑高度并保留滚动。手动拖动分隔条后尊重本次窗口内的选择，后续参数编辑不重置分区。

阀选择区负责动作、开关参数和阀号，原参数表通常仅显示开启时间。“原始参数”展开后可编辑控制方式、位图或单阀编号。原无约束控制方式、线性关系、动态位图和非法固定值等不能由选择器完整表达的配置会自动展开原始参数，来源不会自动改写。1开0关校验、覆盖全部的提醒、0x22仅开启及时间0含义保留。

设备页将电机编号、速度、位置范围和旧方向归入“运动默认值”，默认收起；串口与地址仍直接可用。所有展开开关只改变显示，不参与配置保存，不改变数值或默认来源，也不触发发送。报文预览保留识别字段、实际动作和取值过程，删除配置版本及重复内部参数列表。原始回告、解析结果和日志仍在原页签查看。

面向熟悉趋盛协议的使用者，主窗口保留四页：客户协议格式、命令映射、报文调试、设备与连接。窗口标题去掉括号内容，顶部配置/启用版本栏及参数确认框移除，高级配置页隐藏；错误原因显示在底部配置按钮旁。正常页面只显示编辑、发送及结果所需控件；日志放在调试结果页签，协议细节放入文档。

## 统一配置入口（2026-10-16）

界面统一使用“配置”，不再区分“保存到草稿”“导出草稿”等按钮名称。格式、映射、设备页的三个保存按钮合并为窗口底部“保存配置”，所有页面均可直接使用。底部直接并排显示“保存配置、导入配置、导出配置”三个同尺寸按钮，去掉下拉菜单，移除手动校验、启用操作及待校验提示。

保存提交各页表单和表格中已添加的映射，先结束当前单元格或数字控件编辑，再读取完整内容。尚未点击添加的新映射不参与保存。高级配置页不提供可见入口；复杂关系可通过配置文件导入导出，原有JSON编辑和冲突保护逻辑保留在内部，不影响已有文件兼容。

配置继续使用原有原子写盘和本地路径`%LOCALAPPDATA%/Trendwin/Translation/draft.json`，已有文件无需迁移。保存、导入、应用JSON及启动恢复后自动检查并启用有效内容。配置不完整时仍可保存，但显示“配置有误”且不启用；修复后再次保存即可。写盘失败不切换启用版本，损坏文件不被覆盖或当成有效配置恢复。

自动启用只更新配置快照及默认地址，不连接串口或发送报文，也不清空序号、半帧缓存或在途回告匹配。各请求仍携带入队时的地址快照，保存时可保留原请求等待。参数确认控件及其状态逻辑已删除，导出仍针对已保存配置。

关闭时仅有未保存表单或未应用 JSON 才提示“保存 / 放弃 / 取消”。默认、Esc、关闭提示框均取消退出；保存复用统一入口，失败保留窗口。表单与 JSON 同时修改时禁用关闭提示的保存，要求先处理冲突；调试输入和搜索不触发配置修改提示。

## 命令映射只添加、删除

表格仅显示客户命令、执行动作、参数说明，选中行只确定删除目标。下方“添加新映射”独立于选中行；填写完成点击表格下方的“添加命令映射”后才追加末尾并清空表单。空白或无效内容不创建占位行，重复命令明确提示先删除旧项，不覆盖原记录。删除不改变尚未添加的表单。

已有相对配置直接显示“相对前进”“相对后退”，不加“旧版”前缀；配置与模式不变。新建池继续提供完整59选项、CMD/名称搜索及参数来源，不将旧兼容模板加入新建选项。

移除独立“省略字段”勾选区。停止、复位和查询默认不使用客户参数，仍将命令后相应参数名称保存在`input.omitFields`；普通顺序格式完整解析这些字段，不能因此省掉报文内容。仅mappedCommand旧模式的“无参数短报文”实际省略指定字段，例如Z映射复位可使用`/1ZR\r`。普通运动不使用客户参数时仍须明确填写目标固定数值，不能隐式填零；SDK默认值和固定值同样可用，引用自己声明不用的字段则报冲突。加载旧配置时，仅对mappedCommand中缺少省略列表的停止/复位补齐设置。显式列表及其他元数据保持原值，明确保存前不改写文件，不增加Z专用分支。

## 字段、参数与兼容

同一字段改名同步已有映射的来源及省略设置；增删、排序、类型变化刷新来源，失效关系明确指出，不自动选择替代字段。详见[field-adaptation.md](field-adaptation.md)。

普通映射保留来源字段、固定值、倍数；SDK参数使用“参数、来源、固定值”紧凑表格。停止/复位不显示距离控件。已有offset、round、精确分数及扩展元数据按原记录保留，完整JSON可通过导入导出处理；表单不提供复杂结构或任意字节发送入口。

所有命令使用格式页的帧尾，移除旧responsePolicy和映射独立帧尾设置。目录保留待实现、仅接收等影响使用的状态。教学横幅、协议详情、目录浏览窗口、分类、偏移/取整控件和离线回告解析不常驻界面。

## 调试与验证

发送、手动查询始终可点击。当前表单及已添加映射生成本次配置；有未应用JSON时调试发送使用JSON。不要求保存、校验、启用、确认或设备空闲；连续发送排队，不自动轮询或重发运动。应答与机械完成分开显示。详见[报文调试说明](packet-debug.md)。

本轮使用MSVC2022 14.44 / Qt5.14.2 MSVC 32位构建应用和界面测试。完整52项界面回归、Windows原生11项针对性验证通过（含初始化/清理），编译无警告；已查看四页及无参数复位的实际渲染。新增场景覆盖多个参数字段省略、字段改名、固定目标运动、公共地址保留、SDK固定值和省略引用冲突；原有配置恢复、自动启用及元数据保护继续验证。运行包隔离Qt安装目录后，9项界面与报文验证通过（含初始化/清理），未操作实机。
