# 位置与校准参数

在“设备与连接”的“位置与校准参数”表点击“添加参数组”，填写名称和逗号分隔的原始整数，例如`80,1075,30`，然后点击窗口底部“保存配置”。不自动换算毫米或其他单位，不补空项为0，也不会因保存、修改或选择参数而发送硬件指令。每组1～64项，最多64组；整数范围为±9007199254740991，实际指令仍由SDK检查其协议范围。

表格不规定每组各项的物理含义。样品盘A/B首孔、清洗池校准、开门校准等位置组可按实际协议约定填入XYZ或插入深度；芯片PCLM的三个值分别是触发弹片、对位销、卸载位置，**不是XYZ坐标**。名称可以自定义，不需要使用这些客户示例名称。

在命令映射的取值来源选择“预设 · 名称 · 第N项”。电机位置、虚拟模块XYZ及SDK数字参数均可引用；一个值可供多条指令使用，也可与固定值、客户参数混用。修改预设名称后显示名跟随，内部稳定标识不变；修改参数值后保存，后续转换按新值取用，已有映射不必重建。已排队指令使用转换时的整组快照，不受之后编辑影响。

预设不属于客户报文字段。整组选择“不使用客户参数”后仍可选预设，也不会为预设新增客户列表输入项数。报文本身已有的客户整数列表及输入项数继续遵守原设置：普通顺序格式仍完整读取字段；只有明确采用mappedCommand旧短报文且选择省略客户参数时才按原规则省略。选择预设本身不改变报文布局。

删除参数组或减少项数后，原引用会保留并提示失效，不自动换到其他组或项。请显式修改受影响映射；清单中尚未保存的步骤仍需点击“保存本条修改”，最终再“添加命令映射”。位置表中的空值、空项、小数、重复名称或超范围整数会阻止保存，原配置文件保持不变。

导入[通用示例](../examples/calibration-presets.json)可离线预览：`!PLATE=0\r`将样品盘A示例组传给XYZ，`!PIN=0\r`让0x11电机前进到PCLM示例组第2项。参数0仅按格式读取，不参与目标值。示例值仅用于验证引用，不能视作真实设备的校准结果；程序不会自动导入或执行这些示例，也不实现DI报文更新参数或自动校准动作。

配置根节点的可选`parameterPresets`数组保存`id`、`name`、`values`及未知扩展。引用继续使用field/linear表达式，以`scope:"preset"`区分来源，`field`填写稳定id，`itemIndex`从1开始；省略scope或`scope:"input"`仍表示客户字段。同名输入字段与预设标识不会混用，客户字段改名也不改写预设引用。高级线性换算及allowedValues检查针对取值后的最终结果。
