# 单条命令映射：分析与设计

本轮从 GitHub main 的 5f06edb 开始。先分析用户提供的映射表、HMD6 中文手册与趋盛 V0.1.7 协议，再按设计实施。客户报文仍来自输入框，只连接一个下游串口。

## 界面设计

映射列表只保留客户命令、执行动作、参数说明、反馈时机四列。选中后编辑，不把全部参数铺在表格中。

常用编辑只填写客户命令、执行动作、参数来源、换算倍数和反馈时机。固定值是参数来源中的一个选项。查询没有运动参数，自动隐藏无关项。少数高级关系保留在更多设置和高级 JSON；简单表单保存不能丢失既有精确分数、偏移、取整方式或输入设置。

编辑、保存草稿、校验、启用仍是四个不同状态。选中另一行前保存当前编辑到表单数据，页面“保存到草稿”才更新草稿。任何修改都使校验和设备确认失效；不能误用旧的已启用版本发出新编辑。

## 用户确认后的范围

- A/a：绝对位置；P/p：相对前进；D/d：相对后退。大写在命令接纳后反馈，小写等待完成。一个客户运动命令只发出一个 0x11 运动帧，状态查询另行处理。
- ?、?0、?4：电机位置查询 0x12；&、?23：设备版本查询 0x04。
- 参数先直接使用数值，不依据客户设备步距默认乘十。配置仍支持可选换算。内部参数名沿用趋盛单位约定，不表示已经解决客户与设备的物理单位等价问题。
- P/p 对应前进（远离零点），D/d 对应后退（靠近零点），方向已由用户确认。
- 资料有冲突时以 HMD6 手册为主。阀控制、停止、通讯配置、初始化、指令串和循环均暂缓。

## 协议核对与差异

资料来源：用户提供的《恒永达DT协议-趋盛协议映射总表.xlsx》《HMD6系列注射泵标准用户操作手册》与《TW-RD-0XX功率驱动板通信协议 V0.1.7》。映射表说明引用的是 HLD 测试记录，不能假定全部适用于 HMD6。

| 项目 | 手册与目标协议 | 本轮处理 |
|---|---|---|
| 运动与查询帧尾 | HMD6 3.2.1、3.3.1：运动有 R，查询不需要 R，均以回车结束 | 由每条映射配置字段省略和独立帧尾 |
| A/P/D | HMD6 3.5.2；趋盛 3.2.9：绝对模式4，相对位置模式2，方向1/3，速度与距离24位大端 | 三个通用目标模板，客户字符只在示例 JSON 中 |
| 小写 a/p/d | 手册描述状态不忙；现有框架分离应答与完成 | 作为完成反馈适配，不模拟 HMD6 状态字 |
| ?、?0 | 手册 ? 报告绝对目标位置；映射表把 ?0 作为别名 | 查询趋盛当前电机位置，?0 为验证别名；不声称实现 HMD6 目标寄存器 |
| ?4 | 手册 3.5.8.5：电机脉冲位置；映射表写负反馈 | 查询 0x12 电机位置，负反馈单独展示，不冒充同一概念 |
| &、?23 | 手册 3.5.8.16：版本；趋盛 3.2.3：0x04 请求数据0000 | 显示硬件、IAP、主控版本及设备标识，不重新编码为客户回包 |
| #、?20 | 手册 3.5.8.15：固件校验码；映射表写唯一标识 | 趋盛没有等价校验码，暂不加入，不用 MAC 冒充 |

| T | 手册停止活塞；表格0xD4停止动作集，与直接0x11不同 | 暂缓 |

## 通用解析及状态设计

ASCII 命令码新增“按命令码识别”，只按配置中保存的命令码做最长前缀匹配，固定长度和 HEX 保持原规则。每条映射可配置 input.omitFields 和 input.footer；帧头与剩余字段仍来自共用格式表。未知命令、额外数据、空参数、错误帧尾、越界或非整数一律拒绝组帧。不在解析器中识别 DT、A、P 或问号等特定内容。

相对运动先查询当前位置，只有已回零、空闲且终点在保存的行程范围内才发送 0x11。前置查询与完成查询必须区分：前置查询失败表示运动尚未发出；完成查询失败表示设备可能已经运动，保持状态未知。两者均不自动重发运动。应答策略可以先反馈接纳，但队列仍等待 0x12 确认空闲和本次终点。

本轮不实现位拼接、脚本、多命令组合、循环、TCP、客户回写及完整协议设计器。保留配置表达式与目标模板的扩展边界。
