# 趋盛指令池与映射编辑设计

本轮从 GitHub 最新 main 的 4da1465 开始，用户确认先完成完整可选指令池和映射编辑。目录依据用户提供的《TW-RD-0XX功率驱动板通信协议 V0.1.7》3.2.1–3.2.56；不根据 DT 客户示例决定有哪些趋盛指令。

## 编辑流程

确定客户协议格式后，选中或添加客户命令映射；搜索CMD或中文名称，选择趋盛指令并设置数字参数来源。待实现项的数字参数可以引用客户字段或填写固定整数，未设置的参数保持空白。仅设备主动上报的项标明“仅接收”，不允许作为下发目标。类别筛选、独立目录浏览和长段说明已从简洁界面删除，完整目录元数据仍保留。

目录中的一个指令码可能包含多个动作。0x11现提供前进、停止、后退、复位四个选项，统一固定绝对位置模式；电机和速度用设备默认值，只编辑距离关系。前进/后退已支持发送，停止/复位待实现。旧通用及相对模板只在加载既有配置时兼容显示，不加入新建池。详见[motor-actions.md](motor-actions.md)。变长数据、结构、位组合和模块变体本轮只提供说明。

保存到草稿、校验配置、启用配置保持独立。未实现映射可以保存，与可执行映射共存；转换命中它时明确显示“发送待实现”，不会产生目标HEX报文。目录状态不能从用户JSON改成可执行，只有对应编码器与请求状态逻辑实施后才能开放。

## 资料边界与下一步

文件名为V0.1.7，页眉沿用V0.1.6，修订记录新增24路数字输入。本轮按实际章节收录，保留原文存在的歧义说明：0x01标题与使能位描述、0x21全关闭文字、0x72分段数据要求、0x82回告长度、0x92位宽及0xC1阀泵距离字节重叠等。目录说明不能当作已经验证的线上布局。

下一阶段逐项选择用户需要的指令，确认有歧义的字节布局和设备支持范围，再实现组帧、回告与请求生命周期测试。涉及更新、通讯切换、动作集和事件的指令应单独设计流程，不能简单套用运动完成轮询。
