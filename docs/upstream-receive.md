# 上游串口接收

在「报文调试」切换到「上游接收」，选择上游串口和波特率，点击「连接」。默认参数为115200、8数据位、无校验、1停止位、无流控。该页显示收到的原始字节、完整有效帧和解析字段。

上游和Translation在同一台电脑时，可使用已安装虚拟串口驱动创建的一对端口。上游打开其中一端，Translation选择另一端。比如上游选择COM10，Translation选择与它配对的COM11。现有「设备与连接」中的下游串口单独管理，两端应选择不同的串口。

先导入或保存客户格式。接收使用已保存的格式，将分次到达的半帧拼接为完整报文，也可以从一次接收的数据中拆出多帧。修改格式后保存会更新接收格式，格式变化时清除尚未完成的旧半帧。普通顺序格式不依赖目标命令映射，尚未配置趋盛动作的客户指令也可以接收并解析。

配套极瞳缩写配置可以用下面的内容验证。这里用可读形式表示换行，实际上游应发送换行字节0A以及帧尾0D 0A。

```text
@&5A&01&SCT&1&0;PX=10;10\nEND&?&\r\n
```

原始数据显示ASCII转义文本和HEX，以便检查换行、不可见字节和分隔符。「完整报文」显示通过格式解析的整帧及字段。总字节数统计所有收到的字节，完整帧数统计格式解析成功的报文，错误数记录格式或串口异常。显示内容有容量限制，超过限制时保留最近记录。

「清空接收」清除接收显示、计数和当前半帧缓存，连接保持打开。断开或重新连接后，旧半帧也会被清除。启动软件时由使用者手动连接串口。

此阶段接收结果用于查看和核对，上游应答和自动转发留待后续需求。物理串口和虚拟串口都采用原始字节接收，等待标志、延时、校验和等字段仍按当前格式表的角色处理。
