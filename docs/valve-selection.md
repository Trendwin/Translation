# 电磁阀号选择

单阀和多阀的开关统一在`0x21 电磁阀开关（单路/多路）`中设置，无需手填位图：

1. 选择“关闭选中阀”或“开启选中阀”，再勾选阀号。只选一个就是单阀，多选就是多阀，其余阀保持不变。30路分三组显示，编号旁显示真实协议地址：1号为0x31，30号为0x4E。
2. 全选和清空只改变阀号选择。“开/关选中”模式没有选阀时不操作任何阀，界面会明确提示，不会自动解释成全关。
3. 开启时间仍在下方参数表中选择客户字段、第N个参数或固定值，也可沿用SDK默认。0表示使用设备超时设置，超时配置也为0时持续保持。关闭动作不使用开启时间，软件保留原时间表达式和原报文参数，不自动删改。
4. 多步骤映射须明确“添加到清单”或“保存本条修改”，然后再“添加命令映射”。选择阀号属于当前条的编辑；未保存时切换、排序和最终提交会阻止并保留编辑，可明确保存或放弃。

“按位覆盖全部”是第三种独立动作：**选中阀开启，未选阀全部关闭**。此模式清空选择会关闭全部30路，界面以醒目文字说明，不能把它当作“仅操作选中阀”。

`0x22 电磁阀单路开启（仅开启）`只用于开启一个阀。选择器显示“1号阀（0x31）”等编号，SDK默认49会显示为1号阀。时间0不等于关闭；关闭单阀应回到0x21，选择关闭并只勾目标阀，不新增虚假的0x22关闭参数。

辅助选择区不会在加载时改写来源：固定值和SDK默认显示对应阀号；field/linear/list来源显示为由来源决定，不猜固定阀号。只有用户操作动作或阀号选择器，才把对应mode、valveMask或devId改为constant。下方原三列参数表继续支持默认、字段、列表项、线性表达式和原始固定值；高级及未知扩展随保存、导入和重启保留。修改固定数值也会同步辅助选择区，非法数值显示未确定并由原校验拒绝。

## 通用示例

导入[examples/valve-selection.json](../examples/valve-selection.json)，在调试页预览：

| 输入（转义显示） | 动作 | DATA十六进制 |
|---|---|---|
| `!CLOSE1=0\r` | 关闭1号，其余不变 | `00000001 00000000` |
| `!CLOSE30=0\r` | 关闭30号，其余不变 | `20000000 00000000` |
| `!OPENSET=3000\r` | 开启1/10/11/20/21/30号，时间取第1个参数 | `60180601 00000BB8` |
| `!OPEN30=4294967295\r` | 0x22开启30号，使用32位时间 | `4E FFFFFFFF` |
| `!REPLACE=0\r` | 开启1和3号，关闭所有未选阀，固定时间1000 | `80000005 000003E8` |
| `!DEFAULT22=0\r` | 保留SDK默认，开启1号 | `31 00000000` |

这里使用普通顺序格式，CLOSE等映射不使用参数0也仍完整解析该字段。示例仅验证通用映射能力，不定义客户命令的实际硬件用途。

SDK原布局保持不变：0x21为`(mode << 30) | valveMask`的4字节大端值，再接4字节大端duration；阀1为bit0，阀30为bit29。0x22为1字节devId（0x31～0x4E）加4字节大端duration。不能套用旧版TrendView的0x22布局，也不能把0x23查询结果的位序用于0x21控制。批次仍须前条完整写出且成功ACK才继续；失败停止剩余，ACK不等于机械动作完成。
