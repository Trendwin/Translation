# XYZ虚拟模块与逐条电机配置

## 设置映射

在命令映射页面选择“0xC1 | 虚拟模块控制（XYZ）”，下方四行分别设置虚拟模块编号、X位置、Y位置、Z位置。每行可选客户整数参数或固定值；固定0也是明确设置。三个位置都须提供，不能只填X后默认其他轴不动。把Y/Z固定0表示发送位置0，并不表示忽略该轴。轴是否运动及物理电机绑定由下位机已配置的XYZ模块决定。

模块编号范围0–255，位置范围0–8388607。编号是虚拟模块地址，不是0x11–0x1C物理电机编号。C2绑定与C3配置查询尚未开放，请使用下位机已有配置。

三轴速度沿用设备页面默认运动速度；SDK亦支持按操作保存的各轴速度预置。优先级为SDK预置、设备speedUmPerS、软件初始1000；这不是厂家默认值。位置和速度的实际单位由下位机配置决定，不自动换算。XYZ速度范围0–8388607；如果原设备默认速度超过范围，转换明确失败。SDK明确设置的速度0不被替换。

## 单输入参数示例

导入 `examples/xyz-module-and-motors.json`：

| 输入（`\r`表示回车） | 配置的行为 |
|---|---|
| `!XYZ2000\r` | 模块35：X引用2000，Y固定0，Z固定66051 |
| `!ALL2000\r` | 模块36：X/Y/Z均引用同一个2000 |
| `!M12000\r` | 物理电机0x12前进到绝对位置2000 |
| `!M22000\r` | 物理电机0x13前进到绝对位置2000 |

示例模块编号、位置、速度仅供验证映射与字节，不代表实机配置。上游依然只有一个数值参数；同一个字段可供多项下游参数复用，无需增加客户解析模式。

## 布局和应答

依据功率驱动板协议3.2.40及TrendView `VirtualModuleXYZPage::GenXYZCmd`（参考版本dd0855e0），请求为固定20字节DATA：

| 字节 | 含义 |
|---|---|
| D0 | 模块类型固定01（XYZ） |
| D1 | 模块编号 |
| D2–D4、D5–D7、D8–D10 | X、Y、Z位置 |
| D11–D13、D14–D16、D17–D19 | X、Y、Z速度 |

每项三字节大端。位置/速度范围沿用TrendView界面的0–0x7FFFFF；示例X=0x123456、Y=0、Z=0x010203、三轴速度0x1234的DATA为 `01 23 12 34 56 00 00 00 01 02 03 00 12 34 00 12 34 00 12 34`。

回告严格为结果码1字节与基本状态3字节；完整帧继续校验地址、序号、命令与CRC。有效应答结束本地等待并提示动作完成未确认，不自动轮询、不重发。物理电机停止不会取消XYZ请求；物理电机0x17上报不会被归到XYZ模块。

只开放XYZ类型1。阀泵类型2的原文速度/距离偏移冲突仍未解决，SDK明确拒绝，不猜测布局。C2/C3及其余复杂指令保持原状态。
