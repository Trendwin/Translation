# 按样例拆分文本格式

在客户协议格式页选择“按样例拆分（文本）”。常规操作通过样例和分隔符完成，默认界面不展示花括号模板。原顺序字段ASCII/HEX配置继续使用原逻辑，模板、独立命令及字段表保留在折叠的“高级设置”中。

## 配置步骤

1. 在上方填写共用帧头、帧尾，例如`@&`和`\r\n`。粘贴一条包含这两个边界的完整样例，边界不匹配会指出当前设置。
2. 点击“建议分隔符”，检查“分段、普通字段之间、命令与参数之间、多个参数之间”四项。提示中各有小例子，可使用不同标点或多字节分隔符；没有某种分隔可留空，命令与参数之间必须填写。
3. 点击“拆分预览”。紧凑片段保留全部固定字节和分隔顺序；下方字段表优先列出命令和参数，其后是外层字段。点击片段或字段行设置字段名、含义、类型、固定值和上下限。数字通常建议整数，带前导零的文本建议保留文本；业务用途不会根据客户名称猜测。
4. 点击“应用此命令格式”，再点“解析当前样例”，核对字段实值、未校验提示和执行控制说明。解析不访问串口。
5. 点击底部“保存配置”。样例候选尚未应用时，保存或关闭保存会提醒先应用或“放弃本次拆分”。仅浏览已有命令不视为修改。重启、导入和导出保留已配置命令、字段、已应用样例与分隔符。

例如完整样例：

```text
@&5A&01&SCT&1&0;VECTOR=20,200,3000;10\nEND&?&\r\n
```

分段为`;`，普通字段之间为`&`，命令与参数之间为`=`，参数之间为`,`。软件会保留换行及其后的固定词，拆出三个独立参数。片段中的名字与数值仅是样例，不是代码内置常量。

继续粘贴同一外层结构的`SET=255`完整样例：沿用现有外层字段与扩展，只增加SET的单参数定义。已有命令会按原字段结构展示；应用字段设置是显式操作，不会用新样例替换原参数定义。结构不兼容、参数数量错误、重复/未知字段名、约束不满足均明确拒绝，旧配置保持完整。

`examples/text-template.json`提供完整外层及单/三/零参数命令；`examples/text-template-mapping.json`使用另一套边界与分隔符，可输入`[12|MOVE:234]\r`映射单个趋盛动作。前者仅含格式，没有发送映射。需要单动作转换时，再在命令映射页选择该命令可用的整数参数来源。零参数可用`PING=`样例描述，复杂既有格式仍可在高级设置编辑。

## 拆分边界

每次只接受一条完整报文，完整帧最多4096字节。正文中命令与参数分隔符必须唯一；有多个`=`等符号时拒绝歧义，用户需调整分隔规则或使用高级设置。分隔符不能相同或互相包含，单个分隔符不超过8字节。常规生成器支持一个命令区域，不描述多命令批次或任意嵌套结构。

分段/字段分隔符决定外层区域，参数分隔符决定局部数量；换行后的首个普通词默认视为固定文字，不假定具体词是什么。初次生成的普通词可点选改含义。外层等待、延时、地址、帧类型及校验含义均需用户指定；软件不根据字段值猜业务。已保存的用途、范围、固定值及未知扩展在新增命令时保留。输入和分隔符改动只使候选过期，不直接重建配置；有未应用编辑时须先应用或放弃。

应用操作只生成原有`external.textFormat`，解析和发送仍走同一底层。`sampleEditor`只是可选界面元数据，保存分隔符、已应用样例和上次命令；既有配置没有它也能加载，主界面仍显示命令及参数数量。

## 高级 JSON 结构

```json
{
  "schemaVersion": 1,
  "external": {
    "mode": "textTemplate", "encoding": "ascii",
    "header": "[", "footer": "]\\r",
    "textFormat": {
      "template": "{sequence}|{command}:{arguments}",
      "fields": [{"name":"sequence", "type":"uint", "role":"metadata"}],
      "commands": [
        {"code":"MOVE", "template":"{position}",
         "fields":[{"name":"position", "type":"int", "role":"parameter"}]},
        {"code":"PING", "template":"", "fields":[]}
      ]
    }
  },
  "mappings": []
}
```

字段类型为ascii、uint、int。可选fixedValue按类型精确比较；可选min/max为可精确保存的整数范围（在字段表中编辑，留空可清除）。字段用途：

| role | 用途与转换行为 |
|---|---|
| metadata | 普通元数据，仅展示，不参与发送行为 |
| parameter | 可映射参数，整数可作为该命令的趋盛参数来源 |
| execution | 等待、延时等执行控制，仅解析；转换发送明确拒绝 |
| checksum | 仅提取校验值并明确显示“未校验”，不宣称校验成功 |

省略role兼容为parameter，界面新建外层字段默认metadata。外层名称不可与任何命令局部参数重名；不同命令可各自使用同名参数。映射引用仅在对应命令范围内校验，不会从另一条命令借参数。模板模式不支持旧映射input.omitFields。

## 定界、错误和本轮边界

占位字段名可用中文、字母、数字和下划线，不能以数字开头。模板中每个占位名只出现一次，声明列表必须与其对应；外层必须各有一个command和arguments。相邻占位必须用固定文字隔开。花括号保留用于占位符（固定花括号可写\x7B、\x7D）；固定文字与实际报文为ASCII，可用`\r`、`\n`、`\t`、`\xNN`与`\\`。错误转义明确拒绝。

解析器从左到右按下一段固定文字首次出现的位置定界，不回溯猜测；字段值不能包含该分隔文字。局部参数不允许包含外层arguments后的边界文字。除arguments允许空内容承载零参数命令外，普通字段不得为空或含控制字符。数字必须严格匹配完整十进制文本，不自动去空格，不接受小数、换行或整数溢出。缺参、多参、未知命令、固定字段不符和多余输入均报错。

完整帧及输入缓存上限4096字节。每个模板最多64个占位字段，每份格式最多256条命令。文本模式按统一帧尾分帧，支持半包、粘包；正文不能包含完整帧尾序列。首个定界策略不使用动态正则回溯，不支持字段内部转义分隔符。

当前只支持单包单命令的格式描述和已实现的单趋盛动作映射；不执行多命令批次、等待、延时、校准、动作组合或客户回包。多记录不能通过整数参数结构校验时会明确拒绝，不能只执行第一条。若格式把业务控制值声明为普通元数据，表示用户明确选择仅展示；软件不会靠字段名称猜测业务含义。独立格式解析结果不代表报文可执行，校验值提取也不代表其有效。

每次解析或转换开始均清空输出，失败不留下上次成功字段或目标帧。发送始终重新解析当前输入，不发送旧预览帧。配置中的未知扩展键随表单保存保留；结构改变时已知属性以表单为准。
