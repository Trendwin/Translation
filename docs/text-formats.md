# 通用 ASCII 文本格式

在客户协议格式页选择“文本模板与独立命令参数”。帧头和帧尾在上方统一配置，外层正文模板不重复包含它们。原顺序字段模式和ASCII/HEX配置继续使用原解析逻辑。

## 配置步骤

1. 填写帧头、帧尾与正文模板，例如外层`{sequence}|{command}:{arguments}`。
2. 在外层字段表声明sequence为无符号整数、普通元数据。`command`与`arguments`为保留占位符，不在字段表重复声明。
3. 添加命令格式，例如MOVE的参数模板`{position}`、TRIPLE的模板`{x}/{y}/{z}`；选中每行后，在下方声明其局部字段类型与用途。无参数命令的参数模板和字段表均留空。
4. 输入报文并点击“解析格式”。这一步使用当前表单，无需保存，无需趋盛映射和设备参数。
5. 保存配置可持久恢复格式。需要单动作转换时，在命令映射页建立同命令码的映射，再选择本命令的整数参数来源。“预览”使用已保存配置生成趋盛帧，发送会重新解析当前输入。

`examples/text-template.json`仅含格式，没有发送映射；可输入：

```text
@&5A&01&SCT&255&0;VECTOR=20,-200,3000;10\nEND&?&\r\n
@&5A&01&SCT&1&0;POSITION=234;10\nEND&?&\r\n
@&5A&01&SCT&12&0;PING=;0\nEND&?&\r\n
```

其中type有可选固定值SCT，所以其他类型被明确拒绝。示例中的命令与常量均为配置内容，不是运行代码中的客户分支。`examples/text-template-mapping.json`使用另一套边界、分隔符及命令码，可输入`[12|MOVE:234]\r`生成单条0x11动作帧。示例设备值仅供离线验证。

## JSON 结构

```json
{
  "schemaVersion": 1,
  "external": {
    "mode": "textTemplate", "encoding": "ascii",
    "header": "[", "footer": "]\\r",
    "textFormat": {
      "template": "{sequence}|{command}:{arguments}",
      "fields": [{"name":"sequence", "type":"uint", "role":"metadata"}],
      "commands": [
        {"code":"MOVE", "template":"{position}",
         "fields":[{"name":"position", "type":"int", "role":"parameter"}]},
        {"code":"PING", "template":"", "fields":[]}
      ]
    }
  },
  "mappings": []
}
```

字段类型为ascii、uint、int。可选fixedValue按类型精确比较；可选min/max为可精确保存的整数范围（在字段表中编辑，留空可清除）。字段用途：

| role | 用途与转换行为 |
|---|---|
| metadata | 普通元数据，仅展示，不参与发送行为 |
| parameter | 可映射参数，整数可作为该命令的趋盛参数来源 |
| execution | 等待、延时等执行控制，仅解析；转换发送明确拒绝 |
| checksum | 仅提取校验值并明确显示“未校验”，不宣称校验成功 |

省略role兼容为parameter，界面新建外层字段默认metadata。外层名称不可与任何命令局部参数重名；不同命令可各自使用同名参数。映射引用仅在对应命令范围内校验，不会从另一条命令借参数。模板模式不支持旧映射input.omitFields。

## 定界、错误和本轮边界

占位字段名可用中文、字母、数字和下划线，不能以数字开头。模板中每个占位名只出现一次，声明列表必须与其对应；外层必须各有一个command和arguments。相邻占位必须用固定文字隔开。花括号保留用于占位符（固定花括号可写\x7B、\x7D）；固定文字与实际报文为ASCII，可用`\r`、`\n`、`\t`、`\xNN`与`\\`。错误转义明确拒绝。

解析器从左到右按下一段固定文字首次出现的位置定界，不回溯猜测；字段值不能包含该分隔文字。局部参数不允许包含外层arguments后的边界文字。除arguments允许空内容承载零参数命令外，普通字段不得为空或含控制字符。数字必须严格匹配完整十进制文本，不自动去空格，不接受小数、换行或整数溢出。缺参、多参、未知命令、固定字段不符和多余输入均报错。

完整帧及输入缓存上限4096字节。每个模板最多64个占位字段，每份格式最多256条命令。文本模式按统一帧尾分帧，支持半包、粘包；正文不能包含完整帧尾序列。首个定界策略不使用动态正则回溯，不支持字段内部转义分隔符。

当前只支持单包单命令的格式描述和已实现的单趋盛动作映射；不执行多命令批次、等待、延时、校准、动作组合或客户回包。多记录不能通过整数参数结构校验时会明确拒绝，不能只执行第一条。若格式把业务控制值声明为普通元数据，表示用户明确选择仅展示；软件不会靠字段名称猜测业务含义。独立格式解析结果不代表报文可执行，校验值提取也不代表其有效。

每次解析或转换开始均清空输出，失败不留下上次成功字段或目标帧。发送始终重新解析当前输入，不发送旧预览帧。配置中的未知扩展键随表单保存保留；结构改变时已知属性以表单为准。
