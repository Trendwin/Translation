# 阶段范围、验收与实机确认

## 本轮范围（2026-10-13）

本轮基于四种0x11动作和完整指令池，精简面向协议熟悉者的界面，删除常驻教程、说明和非必要操作入口，保留配置、映射、预览、发送及回告。本轮追加删除反馈时机和独立帧尾，所有命令使用格式页的帧尾，每个匹配回告即时显示。本轮追加协议字段与命令映射联动：同一字段改名自动更新参数引用和省略设置，删除/类型变化指出受影响映射。详见field-adaptation.md和expert-ui.md。

0x11为前进、停止、后退、复位四种，均开放预览与发送，统一固定绝对位置模式4。默认速度、电机来自设备参数或SDK预置；前进/后退映射绝对目标，停止/复位固定零距离。停止可替代同一电机的运动等待，复位按空闲和有效位置确认完成。详见motor-actions.md。

独立QtCore趋盛SDK完整登记56类，30类布局明确的单条控制/查询实现参数补齐、载荷/整帧编码和回告解析，0x11四动作开放后新建池33项可发送。52类可下发指令均可选择；4类设备主动上报报文不能绑定下发映射。动作事件、升级和复杂配置流程暂缓，C1/72布局待确认。DT仅是示例，不内置客户协议识别。详见qusheng-sdk-design.md。

## 资料依据和确认

已核对用户提供的映射表、HMD6操作手册和趋盛V0.1.7协议。协议名称与文件内容不能替代用户指令；本轮有冲突时按用户确认以HMD6手册为主。

用户确认P/p为前进、D/d为后退，参数暂不默认做单位换算。#/?20是固件校验码，目标协议没有等价查询，暂缓；?4取电机位置，负反馈单独展示。大小写命令均在回告到达时显示结果；仍跟踪动作完成，不模拟客户状态字。?/ ?0使用趋盛电机位置查询，不模拟HMD6目标寄存器或状态字。详细设计和差异见mapping-design.md。

## 自动验收

- 完整目录56类指令码及方向、59个含运动预设的选项，与独立预期清单核对。
- 0x11新建池仅四动作，模式固定4；前进/后退动作值1/3不受旧设备方向或注入值影响，速度/电机来自SDK预置或设备参数。
- 停止/复位固定模式、动作、零距离，不能被注入值覆盖；无客户距离、预置编号/速度和旧草稿往返受检。
- 同电机停止优先级、排队运动取消、复位空闲/有效位置、未知位置及拒绝/超时互锁受检。
- 写出与应答区分，慢写/早回告/迟到序号、前置查询和最终回告不能提前交出串口受检。
- 新模板接纳反馈不释放运动占用，确认空闲及本次目标后才完成；兼容项临时显示，不进入新建选项池。
- 待实现映射保存、加载与已支持映射共存；主动上报项及未知操作拒绝作为下发目标。
- 未实现指令命中时无目标帧，用户JSON中的执行标志不能使它进入发送路径。
- 搜索、目标切换和多参数表单保存，不能丢失选中操作或未修改的精确表达式。
- 删除偏移/取整控件后，保存和修改倍数仍保留原offset、round及扩展元数据；共用帧尾、省略字段和发送门禁继续受检。

- 已有固定长度ASCII/HEX配置及十倍换算回归仍通过。
- 新11条单指令按配置解析，目标模式、方向、24位数据和无参数查询载荷受检。
- 改帧头、共用帧尾和多字符命令码后无需修改C++。
- 缺头、错误帧尾、空参数、未知命令、复合报文、非数字、越界、查询多余参数均拒绝目标帧。
- 配置保存再加载保持版本与转换结果一致；半包/粘包和最长命令匹配受检。
- 相对动作前置查询、设备忙/未回零/超时/终点越界不发运动、空闲但终点错误不能完成受检。
- 0x04版本回复、错误序号/长度、设备拒绝受检；0x12负反馈独立解析。
- 现有CRC、长度反码、超时、取消、迟到帧和序号耗尽测试保留。
- 中文映射三列、简化编辑、直接数值/固定值/精确小数倍数、高级关系保真、字段改名跟随、临时重名/空名、原子交换、未保存参数、失效引用、草稿门禁和查询控件隐藏受检。

本机Qt5.14.2 32位分别使用MinGW GCC7.3.0与MSVC2017 14.16.27023构建应用，两套本轮均59项核心、23项界面通过（含初始化/清理），无失败或跳过。独立SDK源代码未改变，上一轮两套71项SDK请求、74项SDK回告通过，逐族独立预期载荷及回告覆盖30族。SDK默认优先级、保留位、通道、正负整数、24/32位边界及主动上报隔离回归继续保留。

检查简洁五页、SDK默认参数和多参数映射中文截图，未见乱码。字段联动、共用帧尾、旧运动完成跟踪、CRC、序号、超时和通用格式解析回归保留。offscreen的propagateSizeHints是测试平台提示。

## 仍需真实设备确认

实机还需确认目标/源地址、DevID、串口波特率、速度与有效行程、绝对动作值、P/D方向与机械安装一致性、0x11方向/模式行为、0x12当前位置和负反馈含义、回零与完成时序，以及0x04版本返回长度（D0–D27基础28字节，可含D28类型）。CRC保留原先样例验证算法，仍应留存真实收发记录。

SDK软件初始值不是厂家默认参数。阀/采样/输出/风扇/电源通道、阀持续时间为零的行为、电源上电延时为零的立即开启行为、输出尺度、21特殊回告头、84扩展和08/09上报序号须核对实机。C1阀泵D6重叠及72索引/数据重叠待正确布局后开放。

相对运动会先查询当前值再校验终点。软件确认空闲与发送之间，设备不得被另一控制器同时移动；外部并行控制不属于当前单下游请求模型。

## 草稿保存修正（MSVC）

新增DraftStore将保存到草稿、应用高级JSON及导入结果写入用户本地JSON，启动优先恢复。未校验通过的草稿也可保存；写入失败不显示已保存，损坏文件读取失败会明确报错并保留原文件。启用和设备确认仍按当前会话执行。

本轮仅使用Qt5.14.2 32位/MSVC2017，应用构建成功，59项核心、27项界面通过，0失败/跳过（含初始化/清理）。新增检验字段改名及全部引用、帧头/帧尾/命令码/设备参数保存后重开一致、切换启动目录仍恢复、未完成草稿恢复、写盘失败后重试和损坏文件保留。全部界面测试使用独立临时草稿文件，未覆盖用户目录。按用户偏好不再默认重复MinGW验收。
