# 阶段范围、验收与实机确认

## 本轮范围（2026-10-10）

在上一阶段可靠的趋盛编解码和请求状态基础上，简化命令映射界面，并加入配置描述的单条运动与查询：绝对位置、相对前进、相对后退、电机位置和设备版本。启动验证配置共11条客户命令，参数直接使用输入数值。

客户报文仍来自界面输入框，软件只有一个下游串口。复杂指令串、阀控制、停止、初始化、通讯参数修改、动作集、循环和客户回包都未进入本轮运行路径。DT仅是示例，不内置客户协议识别。

## 资料依据和确认

已核对用户提供的映射表、HMD6操作手册和趋盛V0.1.7协议。协议名称与文件内容不能替代用户指令；本轮有冲突时按用户确认以HMD6手册为主。

用户确认P/p为前进、D/d为后退，参数暂不默认做单位换算。#/?20是固件校验码，目标协议没有等价查询，暂缓；?4取电机位置，负反馈单独展示。小写指令采用等待动作完成的适配。?/ ?0使用趋盛电机位置查询，不模拟HMD6目标寄存器或状态字。详细设计和差异见mapping-design.md。

## 自动验收

- 已有固定长度ASCII/HEX配置及十倍换算回归仍通过。
- 新11条单指令按配置解析，目标模式、方向、24位数据和无参数查询载荷受检。
- 改帧头、默认/独立帧尾和多字符命令码后无需修改C++。
- 缺头、错误帧尾、空参数、未知命令、复合报文、非数字、越界、查询多余参数均拒绝目标帧。
- 配置保存再加载保持版本与转换结果一致；半包/粘包和最长命令匹配受检。
- 相对动作前置查询、设备忙/未回零/超时/终点越界不发运动、空闲但终点错误不能完成受检。
- 0x04版本回复、错误序号/长度、设备拒绝受检；0x12负反馈独立解析。
- 现有CRC、长度反码、超时、取消、迟到帧和序号耗尽测试保留。
- 中文映射四列、简化编辑、直接数值/固定值/精确小数倍数、高级关系保真、字段失效引用、草稿门禁和查询控件隐藏受检。

本机Qt5.14.2 / MinGW GCC7.3.0 32位构建应用、核心和界面测试通过。核心Qt Test共35项通过，界面8项通过（均含初始化/清理），无失败或跳过。五个页面使用offscreen与Windows字体渲染并视觉检查；propagateSizeHints是测试平台提示。实际日志与截图在本次交付目录中。

## 仍需真实设备确认

未连接真实控制板。本轮数值直传用于功能验证，不表示客户步数、微米或角度已建立物理等价关系。后续由用户另行确定单位及换算。

实机还需确认目标/源地址、DevID、串口波特率、速度与有效行程、绝对动作值、P/D方向与机械安装一致性、0x11方向/模式行为、0x12当前位置和负反馈含义、回零与完成时序，以及0x04版本返回长度（D0–D27基础28字节，可含D28类型）。CRC保留原先样例验证算法，仍应留存真实收发记录。

相对运动会先查询当前值再校验终点。软件确认空闲与发送之间，设备不得被另一控制器同时移动；外部并行控制不属于当前单下游请求模型。
