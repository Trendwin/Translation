# 阶段范围、验收与实机确认

## 本轮范围（2026-10-10）

在上一轮单条运动与查询基础上，本轮补全趋盛协议56类指令目录，以及搜索、类别筛选、中文参数说明和待实现指令的草稿参数编辑。用户明确先完成指令池和映射编辑，不要求这轮实现所有发送与回告。启动验证配置仍为11条客户命令，参数直接使用输入数值。

52类可下发指令均可选择；4类设备主动上报报文仅供查看，不能绑定下发映射。除原有绝对/相对运动、电机与版本查询外，其余显示“发送待实现”，命中后拒绝生成目标帧。复杂指令串、阀控制、停止、初始化、通讯参数修改、动作集、循环和客户回包未进入运行路径。DT仅是示例，不内置客户协议识别。

## 资料依据和确认

已核对用户提供的映射表、HMD6操作手册和趋盛V0.1.7协议。协议名称与文件内容不能替代用户指令；本轮有冲突时按用户确认以HMD6手册为主。

用户确认P/p为前进、D/d为后退，参数暂不默认做单位换算。#/?20是固件校验码，目标协议没有等价查询，暂缓；?4取电机位置，负反馈单独展示。小写指令采用等待动作完成的适配。?/ ?0使用趋盛电机位置查询，不模拟HMD6目标寄存器或状态字。详细设计和差异见mapping-design.md。

## 仍需真实设备确认

未连接真实控制板。本轮数值直传用于功能验证，不表示客户步数、微米或角度已建立物理等价关系。后续由用户另行确定单位及换算。

实机还需确认目标/源地址、DevID、串口波特率、速度与有效行程、绝对动作值、P/D方向与机械安装一致性、0x11方向/模式行为、0x12当前位置和负反馈含义、回零与完成时序，以及0x04版本返回长度（D0–D27基础28字节，可含D28类型）。CRC保留原先样例验证算法，仍应留存真实收发记录。

相对运动会先查询当前值再校验终点。软件确认空闲与发送之间，设备不得被另一控制器同时移动；外部并行控制不属于当前单下游请求模型。
